PROOFPIX SENTINEL

Local prototype dashboard

What this prototype does

Checks ordinary link clicks only on tabs where you explicitly enable it. Uses local heuristics; it does not contact a threat-intelligence provider.

Important limitations

  • No heuristic can prove a link is safe.
  • Redirects and scripted navigation may not be checked.
  • Some legitimate URLs can be flagged and malicious URLs can be missed.
  • Do not use it as a substitute for browser security or professional review.
